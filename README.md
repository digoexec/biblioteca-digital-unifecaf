# Biblioteca Digital UniFECAF

Primeira interface web da biblioteca digital da UniFECAF, desenvolvida com **HTML e CSS** a partir de um protótipo de baixa fidelidade.
Projeto da disciplina Design Web.

## Estrutura

```
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
└── assets/
    └── imagens/
```

## Como abrir

Basta abrir o arquivo `index.html` no navegador.

## O que foi usado

- HTML semântico (header, nav, main, section, article, footer)
- CSS com variáveis, Grid, Flexbox e media queries (900px e 600px)
- Fonte Poppins (Google Fonts)
- Cores da UniFECAF: azul `#0163AA` e verde `#14B367`
